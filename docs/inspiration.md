# Visual language

This file guides atmosphere, not product behavior. The authoritative component contract is [ui.md](ui.md).

Use near-black gridded surfaces, hairline separators, monospaced terminal typography, restrained kiwi-green and orange (`#FF6100`) accents, mostly square workbench panels, dense readable tables, clear written severity, geometric single-color icons, and one obvious primary action. Desktop uses a sidebar and content pane; phone keeps navigation visible above a two-column Home dashboard. Plugin actions show one segmented main progress bar and optional first-level steps.

Avoid trading-dashboard ornament, rainbow charts, photographic wallpaper, per-plugin visual systems, hidden hover-only controls, or marketing-card layouts. Themes, sparklines, and a command palette are future work; they must remain host-owned and cannot expand plugin rendering privileges.
