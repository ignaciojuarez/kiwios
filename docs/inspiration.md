# Visual language

This file guides atmosphere, not product behavior. The authoritative component contract is [ui.md](ui.md).

Use near-black surfaces, subtle borders, restrained kiwi-green accents, 12–16 point corner radii, dense readable tables, clear severity, and one obvious primary action. Desktop uses a sidebar and content pane; phone uses the same hierarchy as a stack. Plugin actions show one main progress bar and optional first-level steps.

Avoid trading-dashboard ornament, rainbow charts, per-plugin visual systems, hidden hover-only controls, or marketing-card layouts inside the app. Themes, sparklines, and a command palette are future work; they must remain host-owned and cannot expand plugin rendering privileges.
