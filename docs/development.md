# Development guide

This document records implementation choices. Public behavior belongs in the protocol and architecture documents, not here.

## Current stack

| Area | Choice |
|---|---|
| Language and UI | Swift 6/SwiftUI for the menu bar and attended setup; host-owned JavaScript/CSS for the PWA; AppKit only where SwiftUI does not expose a macOS API |
| Deployment target | macOS 15; the build host must satisfy Xcode 27's own system requirements |
| Project source | `project.yml`, generated by XcodeGen 2.45 or newer; the generated Xcode project is committed |
| Manifest decoding | pinned `TOMLDecoder` package |
| Local process runner | pinned Swift Subprocess with direct argv, fixed environment, closed stdin, bounded streams, process-group cancellation, and timeout |
| Durable state | pinned GRDB 7.10.0, one migration chain, and a WAL-mode SQLite database |
| Tests | XCTest in `KiwiOSTests` |
| HTTP and PWA | Hummingbird 2.26.0 on fixed loopback, host-owned static web resources |
| Examples | bundled hello-check, monitor, and volume-health; unbundled author template |

Hummingbird, GRDB, `TOMLDecoder`, and Swift Subprocess are the direct third-party runtime dependencies today. Package versions and `Package.resolved` stay committed and are changed deliberately.

## Persistence and queue limits

The first migration creates plugin, approval, job, audit, latest-result, plugin-config, and layout tables. `DatabasePool` provides WAL operation. Database corruption is surfaced as a recovery error; the app does not silently replace the database.

The internal queue admits at most four active executions and 128 additional pending actions. A plugin-scoped resource lock serializes conflicting actions, while a check skips when matching work is already admitted. User-started actions retain database history and audit entries; routine checks retain only their bounded latest result. KiwiOS does not create separate per-run log files or expose a Jobs screen. The shared process transport independently captures at most 64 KiB from stdout and 64 KiB from stderr for its typed result. Job IDs are exact admission identifiers and cannot be admitted twice.

At startup, previously running, queued, or scheduled rows become `interrupted`. The queue does not reload or replay them. Enabled check schedules are reconstructed from validated manifests; each new tick receives a new job ID. Actions are never replayed automatically.

## Package gates

Hummingbird supplies the maintained HTTP parser and server. Its exact version and transitive resolution are committed. App-size and shutdown measurements remain part of the deferred Xcode validation; no build or test result is implied by package resolution.

Use CryptoKit, Keychain Services, Network, ServiceManagement, OSLog, and other platform frameworks directly. Do not add dependency injection, routing, logging, or design-system packages until standard tools demonstrably fail.

## Repository layout

```text
KiwiOS/             menu-bar entry point, runtime, attended setup, and host-owned PWA
KiwiOSTests/        tests mirroring app behavior
plugins/            generic bundled fixtures only
examples/           copyable author templates, not bundled or auto-discovered
catalog/            bundled reviewed-commit metadata and submission policy
docs/               one authoritative document per concern
.github/workflows/  public continuous integration
project.yml         canonical project definition
KiwiOS.xcodeproj/   generated and committed for clone-and-build use
```

The app remains one target, with stable boundaries now split into focused files. Keep those boundaries within one target until another executable needs shared code:

```text
KiwiOS/
  KiwiOSApp.swift                menu-bar lifecycle and graceful termination
  HubRuntime.swift               composition and observable state
  HubSettingsView.swift          compact attended setup and recovery
  Plugin*.swift                  manifest, discovery, policy, and configuration
  Runtime.swift, Watcher.swift   process execution and typed results
  JobQueue.swift                 queue, locks, schedules, cancellation, logs
  Persistence.swift              GRDB records, schema, and migration chain
  HostDoctor.swift               prompt-free host checks
  Web/                           primary host-owned PWA
```

`HubIntegrations.swift` composes native services and installation; `HubRemote.swift` connects the runtime to `RemoteServer`, `RemoteSecurity`, and `TailscaleService`. `KiwiOS/Web/` holds the host-owned PWA. `NativeCapabilities.swift` owns native command gates and snapshots. The template under `examples/` is not an app resource.

Avoid a package-per-layer workspace, protocol wrappers around every type, and separate “domain/data/service” copies of the same model. Extract a Swift package only when another executable target actually needs the code.

## Change rules

- `project.yml` is canonical; regenerate and commit the project after changing it.
- One runner and one validator serve the app, tests, and future CLI.
- Persist externally meaningful states; derive transient view state.
- Preserve queue admission limits, exact job IDs, per-resource serialization, and no-replay recovery when changing scheduling.
- Never perform process, database, or network work on the main actor.
- Validate at trust boundaries, keep internal models typed, and surface failures instead of silently choosing defaults.
- A public manifest or watcher change needs a version decision, contract update, fixture, test, and changelog entry.

Run the same checks as CI:

```sh
xcodegen generate
xcodebuild -project KiwiOS.xcodeproj -scheme KiwiOS -destination 'platform=macOS' CODE_SIGNING_ALLOWED=NO test
./plugins/hello-check/check.sh
git diff --check
```

`HubPresentation.swift` groups native capability and remote-access state. Configuration CAS revisions, pending uninstall records, secret ownership, and interrupted-secret-write markers extend the existing migration chain. The former native dashboard screens and their duplicate plugin-data renderers were removed when the PWA became the primary UI; recurring manifest checks and historical scheduled-row decoding remain.
